# 未知之城 · Unknown City

**3D 末世城市探索与生存游戏原型。** 工作代号为 `unknown-city-prototype`；名称可在美术与玩法定型后调整。

本仓库用于管理原型说明、后续游戏工程、模块化建筑与角色资源，以及建模到引擎的交接规范。目标是先让 **1 号居民楼** 的出生、室内探索和垂直通行形成可验证的小闭环，再逐步连接街道与其他城市区域。

## 当前状态

- 已建立仓库骨架、中文说明、Unity 忽略规则和 Git LFS 资源规则。
- 本次未接收到已有工程或模型文件；当前仓库没有可运行场景、角色控制器或构建包。
- Unity 编辑器版本、渲染管线与插件版本尚未锁定。接入已有工程时，以其真实配置为准，避免为了初始化而升级或重做。
- `game/` 目前是工程接入入口；**不能直接把仓库根目录或 `game/` 当作 Unity 工程打开**。

## 原型方向

- 3D 自由移动、第三人称观察、多层建筑探索；楼梯、天台与地下区域支持垂直路线。
- 以模块化墙体、楼板、门窗、楼梯和掩体减少制作量；优先验证通行、碰撞和镜头。
- 交互提示和原型说明默认使用简体中文，源码与路径使用稳定的英文命名。
- 玩法保留战斗、资源搜集和据点建设的发展空间；本轮范围集中在 1 号楼的接入与检查。

具体范围与下一阶段检查项见 [原型说明](docs/PROTOTYPE.md)。

## 目录用途

| 路径 | 用途 |
| --- | --- |
| `docs/` | 原型范围、版本管理规则、资源来源与交接记录 |
| `game/` | 游戏工程接入说明；拟将真实 Unity 工程放在 `game/UnknownCity/` |
| `art/source/models/` | 可编辑模型源文件，如 Blender / Maya 文件 |
| `art/source/textures/` | 可编辑贴图源文件，如 PSD |
| `art/exports/` | 待审阅、待接入引擎的导出资源 |
| `art/references/` | 有权存储的概念图、设计参考与来源说明 |
| `.gitignore` | 排除 Unity 缓存、构建输出、本地设置和常见私密文件 |
| `.gitattributes` | 文本换行与二进制资源的 Git LFS 规则 |

空美术目录用 `.gitkeep` 保留。Unity 的 `Assets/`、`Packages/`、`ProjectSettings/` 将由真实工程提供，不预造工程配置或资源 GUID。

## 开始使用

安装 Git 和 Git LFS 后，在 Git Bash 或终端运行：

```bash
git lfs install
git clone https://github.com/zgbnb111222333-cpu/-.git unknown-city-prototype
cd unknown-city-prototype
git lfs pull
git status
```

当前只有文本骨架，没有需要下载的 LFS 资源。后续新增模型前也必须先安装 Git LFS。

1. 阅读 [游戏工程接入说明](game/README.md)，优先复用已有工程。
2. 阅读 [美术资源规范](art/README.md)，将源文件与引擎用资源分开管理。
3. 按 [版本管理指南](docs/VERSION_CONTROL.md) 检查 `.meta`、大文件、许可证与暂存区，再提交。

## 版本管理速记

| 内容 | 管理方式 |
| --- | --- |
| 代码、说明、场景和预制体文本、资源 `.meta` | 普通 Git；资源与 `.meta` 成对提交 |
| Unity 工程配置 | 提交 `Assets/`、`Packages/`、`ProjectSettings/`，保留版本与依赖锁定文件 |
| 模型、贴图、音视频等二进制资源 | 按已提交的 `.gitattributes` 使用 Git LFS |
| Unity 缓存、临时文件、构建产物 | 由 `.gitignore` 排除；构建发布包另行分发 |
| 超大原始素材、不可公开分发的资源 | 使用适合其权限的外部存储，登记版本、取得方式与校验值 |

本仓库初始化时为公开仓库。Git LFS 也不提供私密保护；接入资源前需确认允许在该仓库分发。此骨架未为第三方资源授予许可，也未选择项目开源许可证。
