# 原型范围与接入检查

## 定位

工作名：**未知之城 / Unknown City**。以 3D 末世城市中的建筑探索为起点，支持第三人称观察、自由移动、资源互动，并为后续战斗与据点建设保留空间。

本阶段以 1 号居民楼为最小场景单元。沿用固定建筑骨架、局部路线变化和模块复用的方向；先把可读、可走、可返回做稳，再考虑随机刷新和城市规模扩展。整体体验应控制挫败感，灰盒阶段优先低成本验证。

## 下一个可验证里程碑：1 号楼接入

以下是建议验收项，均待拿到工程后实测：

- [ ] 记录工程路径、编辑器精确版本、依赖和真实入口场景。
- [ ] 出生点落在预定三层房间内，角色不穿地、不被墙体卡住。
- [ ] 主要楼梯与楼层有连续碰撞；从出生房间能走到建筑出口。
- [ ] 用简单材质和标识区分可走、封闭、可交互区域；检查死角与返回路线。
- [ ] 第三人称镜头在门口、楼梯、狭窄房间不会严重遮挡角色。
- [ ] 核对天台、地下层与外部路线的现状；未完成部分标记为待办。
- [ ] 中文提示可读且字体可合法分发；没有误将英文占位当作汉化完成。
- [ ] 从干净克隆恢复资源后可打开工程，资源引用与 `.meta` 没有丢失。
- [ ] 记录实测机器、运行问题和截图，再决定下一步扩展范围。

## 制作约定

- 建筑按墙体、门窗、楼板、楼梯、栏杆与掩体拆分；尺寸和枢轴先用现有工程验证。
- 不把设计图上的标注直接当成已实现功能，也不为旧成果缺少验证而从头重做。
- 资源路径使用英文与稳定编号，如 `Building01_Wall_A`；玩家可见文字使用简体中文。
- 世界观、完整城市、复杂治理、联网、全量程序化生成均不作为仓库初始化的实现任务。

后续确认引擎版本、渲染管线与模块尺寸时，在本文件记录实际值和确认日期。
